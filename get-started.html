Introduction

Overview

HERE gives you maps, location data, and developer tools to build location-based experiences. This page is the shortest path from a blank editor to a working feature.
If you prefer to learn by watching, jump to the video library. If you'd rather copy a working project and edit it, head to the sample projects below.

Quick start

In four steps

  1. Step 1

    Create an account and get an API key

    Every HERE request needs an API key. Sign up for a free developer account, create a project, and generate a key from the platform dashboard. Free plans include enough monthly transactions to build and test a real integration.

    Keep your key out of client-side code in production. Use environment variables or a small proxy so the key never ships in your bundle.

    Create a free developer account Generate an API key Keep your credentials safe
  2. Step 2

    Make your first request

    Start with Geocoding & Search. A single GET request turns an address into coordinates and confirms your key works end to end. You can run it from your terminal with curl, paste the URL into a browser, or call it from any HTTP client.
    Once you see a response, try Routing or Map Rendering to get a feel for how products connect.

    Geocoding & Search quick start Calculate a route Render your first map
  3. Step 3

    Learn the core concepts

    A short read goes a long way. The basics cover how authentication works, how coordinates are expressed, how rate limits apply, and how HERE products fit together so you can pick the right one for the job.
    Skim the glossary if you're new to mapping terms like geocoding, isolines, or map tiles.

    Intro to mapping concepts Rate limits and quotas Mapping glossary
  4. Step 4

    Build your first integration

    When you're ready to ship something real, follow a guided tutorial. Each one walks you from an empty project to a working feature with full code you can adapt. Pick the one that matches what you're building.
    If you'd rather start from a working example, browse the use cases and clone the closest match.

    Follow a guided tutorial Browse the use cases Sample projects on GitHub
