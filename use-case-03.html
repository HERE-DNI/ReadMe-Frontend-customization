Routing API

Calculate a route between two locations

Provide turn-by-turn directions between any two points with realistic ETAs and detours powered by live traffic. Ideal for navigation, delivery, ride-hail, logistics, and fleet operations.

6 minute read Last updated: Jan 6, 2026

Introduction

Overview

A routing experience takes an origin and a destination, picks a travel mode, and returns a polyline plus turn-by-turn maneuvers. HERE Routing supports car, truck, pedestrian, bicycle, scooter and public transit, with options for tolls, ferries, and vehicle restrictions.

Layering HERE Real-Time Traffic on top of Routing produces realistic arrival times, dynamic re-routes around incidents, and a visible congestion layer on the map — all behind a single API key that also powers the Maps API for JavaScript visualization.

Typical scenarios

When to use

  • Door-to-door navigation

    Guide a driver, cyclist or pedestrian from A to B with full turn-by-turn maneuvers and live ETAs.

  • Delivery dispatch

    Calculate the most efficient route for a delivery vehicle, respecting truck attributes and current road conditions.

  • Dynamic re-routing

    Detect incidents along the active route and offer a faster alternative in real time.

Flow

How it works

  1. 1

    Collect origin and destination

    Capture both endpoints from the user as addresses, place picks, or map clicks. Convert addresses to coordinates if needed.

  2. 2

    Request a traffic-aware route

    Call the HERE Routing API with the chosen transport mode and a departure time so HERE factors current and predicted traffic into the response.

  3. 3

    Render, monitor, and re-route

    Draw the returned polyline on the map, fetch live incidents along the corridor, and trigger a re-route when conditions change the optimal path.

// Serve the key from your backend in production — never ship it in a bundle.
const API_KEY = window.HERE_API_KEY;

const platform = new H.service.Platform({ apikey: API_KEY });
const defaultLayers = platform.createDefaultLayers();

const map = new H.Map(
  document.getElementById('map'),
  defaultLayers.vector.normal.map,
  { zoom: 10, center: { lat: 52.52, lng: 13.405 }, pixelRatio: devicePixelRatio }
);

new H.mapevents.Behavior(new H.mapevents.MapEvents(map));
H.ui.UI.createDefault(map, defaultLayers);

async function routeWithTraffic(origin, destination) {
  const url = new URL('https://router.hereapi.com/v8/routes');
  url.searchParams.set('transportMode', 'car');
  url.searchParams.set('origin', `${origin.lat},${origin.lng}`);
  url.searchParams.set('destination', `${destination.lat},${destination.lng}`);
  url.searchParams.set('return', 'polyline,summary,actions,instructions');
  // "now" makes HERE factor live and predicted traffic into the ETA.
  url.searchParams.set('departureTime', 'now');
  url.searchParams.set('apiKey', API_KEY);

  const response = await fetch(url);
  if (!response.ok) throw new Error(`Routing failed: ${response.status}`);

  const { routes } = await response.json();
  if (!routes.length) return null;

  const section = routes[0].sections[0];
  const line = H.geo.LineString.fromFlexiblePolyline(section.polyline);

  map.addObject(new H.map.Polyline(line, { style: { lineWidth: 6 } }));
  map.getViewModel().setLookAtData({ bounds: line.getBoundingBox() });

  document.getElementById('distance').textContent =
    `${(section.summary.length / 1000).toFixed(1)} km`;
  document.getElementById('eta').textContent =
    `${Math.round(section.summary.duration / 60)} min`;

  const incidents = await incidentsAlong(section.polyline);
  document.getElementById('incidents').textContent = incidents.length;

  return { section, incidents };
}

async function incidentsAlong(polyline, radiusMetres = 500) {
  const url = new URL('https://data.traffic.hereapi.com/v7/incidents');
  // A corridor query keeps the response scoped to the route itself.
  url.searchParams.set('in', `corridor:${polyline};r=${radiusMetres}`);
  url.searchParams.set('locationReferencing', 'shape');
  url.searchParams.set('apiKey', API_KEY);

  const response = await fetch(url);
  if (!response.ok) throw new Error(`Traffic failed: ${response.status}`);

  const { results = [] } = await response.json();
  return results;
}

routeWithTraffic(
  { lat: 52.53086, lng: 13.38469 },
  { lat: 52.49404, lng: 13.42917 }
).catch(console.error);
