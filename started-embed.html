Send your first HERE API request

Create a HERE account, generate an API key, and use it to send your first HERE API request.

3 minute read Last updated: Nov 12, 2026

Introduction

Overview

HERE gives you maps, location data, and developer tools to build location-based experiences. This page provides a direct path from a blank editor to a working API request.

Quick start

In four steps

  1. Step 1

    Sign up for a HERE account

    Create a HERE account to access the HERE platform and generate credentials for your applications.

    1. Go to the HERE platform.
    2. Select Sign up.
    3. Enter your email address and complete the registration steps.
    4. Verify your email address.
    5. Click Sign in on the HERE platform and enter your HERE account credentials.
    Go to the HERE platform
  2. Step 2

    Create a project and app

    A project contains the HERE services your application can use. An app represents your application and stores the credentials it uses to access those services.

    1. Select Projects Manager from the launcher.
    2. Select Create new project, fill in the required fields, and then select Create.
    3. In the project, select the Resources tab.
    4. Link the HERE service that you want to call. For the request in this guide, link Geocoding and Search.
    5. Select Access Manager from the launcher.
    6. On the Apps tab, select Create new app.
    7. Enter the required information, then select Create app.
  3. Step 3

    Generate an API key

    An API key authenticates your application when it sends requests to HERE APIs.

    1. On the Apps tab, select the app that you registered.
    2. On the Credentials tab, click Create API key.
    3. Copy the API key. You will use it to authenticate the request in the next step.
  4. Step 4

    Send your first request

    This request uses your API key to call the Geocoding and Search service that you linked to your project.

    Copy 
    curl "https://geocode.search.hereapi.com/v1/geocode?q=Berlin&apiKey=YOUR_API_KEY"

    The request returns a JSON response with location results:

    Copy 
    {
  "items": [
    {
      "title": "Berlin, Deutschland",
      "id": "here:cm:namedplace:20187429",
      "resultType": "locality"
    }
  ]
}

    If the request returns an authentication error, verify that you replaced YOUR_API_KEY with the complete API key and linked Geocoding and Search to your project.
