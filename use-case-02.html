Introduction

Overview

A place search experience accepts a free-form query (for example "Rue Bourdas, Parker" or "coffee near me"), resolves it to one or more candidate locations, and renders them on an interactive map. With HERE you combine two services: the Geocoding & Search API to find candidates and the Maps API for JavaScript to display them.

Both services share a single freemium API key, so the same credential gets you from "first request" to "production" without switching SDKs.

Typical scenarios

When to use

  • User search

    A user types an address or place name and you center the map on the result.

  • Autocomplete

    Show suggestions as the user types, powered by the /autosuggest endpoint.

  • POI discovery

    Surface restaurants, ATMs, EV chargers and other categories around a viewport.

Flow

How it works

  1. 1

    User enters a query

    Capture the input from a search field. Pass the user's current viewport (at=lat,lng) for better local relevance.

  2. 2

    Convert query → coordinates

    Call the Geocoding & Search API: /geocode for known addresses, /discover for free-form queries, or /autosuggest for as-you-type suggestions.

  3. 3

    Render the result on the map

    Initialize a map with the Maps API for JavaScript, drop a marker at the returned coordinates, and pan/zoom to the result.

 JS
Copy 
// Serve the key from your backend in production — never ship it in a bundle.
const API_KEY = window.HERE_API_KEY;

const platform = new H.service.Platform({ apikey: API_KEY });
const defaultLayers = platform.createDefaultLayers();

const map = new H.Map(
  document.getElementById('map'),
  defaultLayers.vector.normal.map,
  { zoom: 12, center: { lat: 52.52, lng: 13.405 }, pixelRatio: devicePixelRatio }
);

new H.mapevents.Behavior(new H.mapevents.MapEvents(map));
H.ui.UI.createDefault(map, defaultLayers);

let marker;

async function search(query) {
  const center = map.getCenter();
  const url = new URL('https://discover.search.hereapi.com/v1/discover');
  url.searchParams.set('q', query);
  // Bias results toward what the user is currently looking at.
  url.searchParams.set('at', `${center.lat},${center.lng}`);
  url.searchParams.set('limit', '1');
  url.searchParams.set('apiKey', API_KEY);

  const response = await fetch(url);
  if (!response.ok) throw new Error(`Discover failed: ${response.status}`);

  const { items } = await response.json();
  if (!items.length) return null;

  const { position, title } = items[0];

  if (marker) map.removeObject(marker);
  marker = new H.map.Marker(position);
  map.addObject(marker);
  map.getViewModel().setLookAtData({ position, zoom: 16 });

  return title;
}

document.getElementById('search').addEventListener('submit', (event) => {
  event.preventDefault();
  search(new FormData(event.target).get('q')).catch(console.error);
});

Building blocks you'll need

Required

  • Geocoding & Search API

    REST API that resolves text into geo-coordinates and structured place data. Endpoints include /geocode, /discover, /autosuggest, /browse and /lookup.

    Open

  • Maps API for JavaScript

    Lightweight client library for embedding interactive maps in a browser. Provides map rendering, markers, info bubbles, UI controls and event handling.

    Open
